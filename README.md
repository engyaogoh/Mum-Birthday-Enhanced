# Mum Birthday — Embroidered Edition

A duplicate of [Mum-Birthday](https://github.com/engyaogoh/Mum-Birthday) rebuilt with the **`frontend-design`** and **`web-design-guidelines`** Hermes skills.

Direction: **"The Embroidered Life"** — a linen-and-thread heirloom drawn from Mum's craft (cross-stitch). Thread-box palette, dashed seam borders, stitched corner brackets, and a signature SVG heart that embroiders itself on scroll.
